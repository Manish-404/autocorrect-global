Honest limits

  • Not tested yet: Outlook and WhatsApp (testing them needs a signed-in account), Notepad, other desktop chat apps, code editors, games. They are ordinary Windows text boxes, so they should work, but we have not checked each one. tools/compat lets you test yours.
  • A program running as administrator ignores a normal script. Run the script as administrator too (right-click, Run as administrator).
  • Games with anti-cheat, remote desktop windows and some secure input fields can block scripts that type for you.
  • Hindi needs a keyboard that types Devanagari letter by letter, such as Windows' Hindi Traditional (INSCRIPT). Phonetic tools that compose whole words first were not tested.

How it works

One rule per typo. Thousands of rules.

Each script is a plain text file for AutoHotkey, a free, open-source Windows tool that can watch the keyboard. A rule is a single line, called a hotstring.

1

You type

The script sits in the tray and sees each key you press, in any program.

nhi
2

You end the word

Space, Enter or punctuation (and the Hindi danda ।) tells it the word is finished. It checks the word against its list.

Space→::nhi::nahi
3

It fixes it

It erases the typo and types the right word, keeping your capitals: Nhi becomes Nahi, NHI becomes NAHI.

nahi

Safe by design

  • Only words that are clearly misspelled are fixed. Spellings people really use (kyu and kyun, acha and accha) are left alone.
  • Ambiguous or risky ones are in a commented-out block at the end of each file. Switch on the ones you agree with.
  • The scripts make no network calls and store nothing. You can read every line.
  • Delete one line to remove a fix you don't like. Press a hotkey on a selected word to add your own.

How the Hinglish list was built

Hinglish has no official spelling, so the list is generated from about 11,700 known words, then filtered hard. A fix is thrown away if it would turn a real word into another, is an English word, could mean two things, or clashes with the English script.

On words the generator never saw, 3 in about 200 rare words were changed, all alternate spellings. That's why every fix is one line you can delete.

Install

Three minutes, no installer for the scripts.

  1. Get AutoHotkey v1.1

    It is free and open source. Download it from autohotkey.com and choose v1.1. The scripts are written for v1.1, not v2.

  2. Download the scripts

    Download the ZIP and unzip it anywhere.

  3. Double-click what you want

    Run one, two or all three. A green H appears in the tray. Each script only touches its own language.

  4. Start with Windows (optional)

    Press Win + R, type shell:startup, and drop a shortcut to each script in that folder.

  5. For Hindi: add a Hindi keyboard

    Settings, Time & language, add Hindi, then add the Hindi Traditional keyboard. Keep the Hindi file saved as UTF-8 with BOM.

Questions

Good to know.

Does it send what I type anywhere?

No. The scripts contain no network code and keep nothing. They only compare the word you just typed with their list, on your own PC. They are short, plain text files, so you can check.

What is AutoHotkey, and is it safe?

AutoHotkey is a free, open-source (GNU GPL v2) tool for Windows that can watch the keyboard and type for you. AutoCorrect Global is a set of short, readable AutoHotkey scripts, built on it. It is an independent project, not made by or affiliated with the AutoHotkey project. Get AutoHotkey only from autohotkey.com.

What if it changes a word I meant?

Open the script in any text editor and delete that one line (use search to find it), then reload the script. Names and rare words are the usual cause. In our test on words the Hinglish generator had never seen, 3 of about 200 rare words were changed, all of them alternate spellings.

Why one script per language?

So each stays small, and so you only run what you need. They are built so they never both rewrite the same word: the Hinglish list drops anything the English script would also change.

Does it work on Mac, Linux or my phone?

No. It needs Windows and AutoHotkey v1.1. The idea would port, but this project does not.

Can I use AutoHotkey v2?

Not as is. The scripts use v1.1 syntax, so install v1.1 (you can have both versions side by side).

I also type Marathi.

Some Hindi fixes (like शक्ती → शक्ति) are correct in Marathi. Delete those lines from the Hindi script, or leave it off.

Will my antivirus complain?

Some security tools are cautious about any script that watches the keyboard, even a harmless one. AutoHotkey is a well-known tool and these scripts are readable text, but if yours objects, add an exception for the folder.

How do I report a wrong fix or add words?

Open an issue or a pull request on GitHub. The Hinglish word lists live in tools/hinglish/lex, and one command rebuilds the file.
